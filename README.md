# LOUNGE'X 후보지 관리

라운지엑스 신규 출점 후보지를 등록·추적하는 내부용 대시보드.
[loungex-brand](https://sigmaideas.github.io/loungex-brand/) 와 같은 디자인 시스템(Pretendard · 사이드바 + 카드 레이아웃 · #4263eb 액센트)을 씁니다.

**→ https://sigmaideas.github.io/loungex-candidate/**

![미리보기](preview.png)

## 데이터 기준

구글 시트 **"4. 후보지"** 표의 항목 체계를 그대로 따릅니다.

| 시트 열 | 앱 항목 |
| --- | --- |
| 구분 (직/가/베) | 직영 · 가맹 · 베이커리 |
| 경로 | 임대 · 매입 · 라운지 |
| 담당자 · 건물명 · 위치 | 담당 · 후보지명 · 주소(또는 네이버 지도 링크) |
| 결과 | 검토중 · 제안완료 · 진행중 · 계약완료 · 드랍 · 기타 |
| 층수 · 전용 면적 | 층 · 면적(평) |
| 보증금 · 고정 임차료 · 수수료율 · 건물 관리비 · 권리금 | 임대 조건 |
| 예상손익 · 계약 가능시기 · 기타 · 계약 완료 | 진행 |

**금액 단위는 시트와 같은 천원**입니다. 저장은 천원으로 하고, 화면에는 억·만원으로 환산해 보여줍니다
(`73,600` → `7,360만원`). 입력 칸 아래에도 환산값이 바로 뜹니다.

시트에 없는 두 가지는 앱이 자동으로 만듭니다.

- **지역** — 건물명·주소에서 구/시를 뽑아 채웁니다 (`서울 중구`, `경기 광명시` …)
- **초기투자** — 보증금 + 권리금

`보증금 협의중` `임차료 입찰` 처럼 숫자가 아닌 칸은 값을 0으로 두고 **조건 비고**에 원문을 남깁니다.

## 구성

프런트는 빌드 없는 정적 파일이라 GitHub Pages 에 그대로 올라갑니다.
팀 공유가 필요하면 `worker/` 를 Cloudflare 에 배포합니다.

```
index.html            화면 구조
style.css             디자인 시스템 (loungex-brand 토큰 그대로)
app.js                상태 · 렌더 · 저장 · 동기화 · 시트 가져오기
config.js             워커 주소 (팀 공유용, 비워 두면 로컬 모드)
data/candidates.json  구글 시트에서 뽑은 후보지 79곳 (첫 실행 시 자동 로드)
worker/               팀 공유용 Cloudflare Worker + KV
```

외부 의존성은 CDN — Pretendard(폰트), Chart.js(분석 차트), Lucide(아이콘), SheetJS(엑셀 파일을 읽을 때만 로드).

## 데이터 저장

### 로컬 모드 (기본)

브라우저 localStorage 에만 저장됩니다 (`loungex.candidates.v2`).
같은 브라우저에서만 보이고, 공유·백업은 JSON 내보내기로 합니다.

### 팀 공유 모드

`worker/` 의 Cloudflare Worker 를 배포하고 **가져오기 · 내보내기 → 팀 공유 설정** 에
워커 주소와 팀 키를 넣으면 켜집니다. 배포 방법은 [worker/README.md](worker/README.md).

- 바뀐 항목만 서버로 보내고, 20초마다 · 탭을 다시 켤 때 서버와 맞춥니다
- 두 사람이 같은 후보지를 고치면 `updatedAt` 이 최신인 쪽이 남습니다
- 삭제는 tombstone 으로 60일 기록해서, 오프라인이던 브라우저가 삭제된 항목을 되살리지 않습니다
- 연결이 끊겨도 로컬에는 계속 저장되고, 다시 연결되면 밀린 변경을 보냅니다
- 상단 배지가 상태를 보여줍니다 — 초록(동기화됨) · 파랑 점멸(전송 중) · 주황(팀 키 확인) · 빨강(연결 실패)

## 시트에서 가져오기

**가져오기 · 내보내기 → 구글 시트 · 엑셀 가져오기** 에서 세 가지 방법을 씁니다.

- `.xlsx` `.xls` `.csv` `.tsv` 파일 올리기
- 시트에서 범위를 복사해 붙여넣기
- 구글 시트 공개 CSV 주소 (파일 → 공유 → 웹에 게시 → 쉼표로 구분된 값)

첫 줄을 머리글로 읽어 열을 자동으로 연결합니다. `건물명` `보증금` `고정 임차료` `결과` 같은
시트 머리글은 그대로 인식하고, 위쪽에 제목·단위 표기 줄이 있어도 머리글 줄을 찾아 건너뜁니다.
틀린 연결만 화면에서 바꾸고 가져오면 됩니다.

값 표기도 알아서 정리합니다.

- `50,000` → 50,000천원 · `1억5000만` → 150,000천원
- `직` `가` `베` → 직영 · 가맹 · 베이커리
- `검토중` `드랍` `진행 중` `제안완료` → 결과값
- 위치 칸이 링크면 지도 링크로, 주소면 주소로 (`- 네이버 지도` 꼬리표는 떼고)

`후보지명이 같으면 갱신` 을 켜 두면(기본값) 시트를 원본으로 두고 계속 다시 가져와도 중복이 쌓이지 않습니다.

내보내기는 **CSV**(시트와 같은 열 순서, 한글 깨짐 방지 BOM 포함)와 **JSON**(백업·병합용) 두 가지입니다.

## 로컬에서 보기

```bash
python3 -m http.server 8899
# http://localhost:8899
```

`data/candidates.json` 을 fetch 로 읽기 때문에 `file://` 로 직접 열면 첫 데이터가 안 들어옵니다.
워커의 CORS 허용 목록에 `localhost:8899` 가 들어 있어서 팀 공유도 로컬에서 그대로 테스트됩니다.

## 배포

GitHub Pages 로 서비스합니다. `index.html` 의 `style.css?v=2` · `app.js?v=2` 는 캐시 버스팅용이라
파일을 고칠 때 숫자를 함께 올려야 브라우저가 새 파일을 받습니다 (Pages 가 10분 캐시).
